Write down the assembly instruction the kernel is panicing at. Which register corresponds to the variable num?
Faulting assembly instruction: lw a3, 0(zero) # 0 <_entry-0x80000000>
Assembly explanation:
lw (load word): Loads a 32-bit value from memory into register a3.
zero register (x0): Always holds the value 0.
0(zero): This means load from memory address 0x0 (NULL pointer).
Destination register: a3 --> This is where the loaded value is stored.
Register corresponding to num: a3

Why does the kernel crash? Is address 0 mapped in the kernel address space? Is that confirmed by the value in scause above?
The kernel attempts to dereference a NULL pointer (0x0).
The NULL pointer (0x0) is not mapped in the kernel address space.
This causes a load page fault (scause = 0xD), leading to a kernel panic. So scause helps confirm the kernel crash.
